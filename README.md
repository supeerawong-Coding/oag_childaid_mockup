# OAG ChildAid mockup

เว็บต้นแบบ React + TypeScript + Vite ใช้ข้อมูลสมมติ บันทึกใน localStorage ของเบราว์เซอร์

ต้องใช้ Node.js 22.12 ขึ้นไป คำสั่ง npm ของเครื่องนี้จะเลือก Node.js ที่มากับ Codex อัตโนมัติหาก Node.js ของระบบเก่าเกินไป

## เปิดใช้งาน

```sh
npm install
npm run dev
```

เปิด http://127.0.0.1:5173

## เผยแพร่บน GitHub Pages

ในรีโป GitHub ไปที่ **Settings → Pages → Build and deployment** แล้วเลือก
**Source: GitHub Actions** จากนั้น push ขึ้น `main` หรือกด **Run workflow**
ในแท็บ **Actions → Deploy to GitHub Pages**

Workflow จะรัน `npm run build` และเผยแพร่เฉพาะไฟล์ใน `dist/`
จึงไม่ต้อง commit ไฟล์ `dist/` ที่ build ใหม่ทุกครั้ง เมื่อ deploy สำเร็จ
ลิงก์เว็บจะแสดงใน **Settings → Pages**

## ภาพรวมระบบ

Dashboard ใช้กราฟเส้นรายเดือน กราฟโดนัทสำหรับสถานะและบทบาทเด็ก
กราฟแท่งสำหรับเปรียบเทียบ และแผนที่ประเทศไทยรายจังหวัดแบบ SVG
กราฟทั้งหมดใช้ตัวกรองร่วมกันและคลิกดูรายการได้ แผนที่ใช้ไฟล์ขอบเขต
ในโปรเจกต์ ไม่ต้องใช้ API key ดูที่มาและการเติมขอบเขตสตูลใน src/data/README.md
ตรวจ dashboard บนเบราว์เซอร์ด้วย `node tests/dashboard.cjs` ขณะเปิด dev server

ข้อมูลตัวอย่างใช้สถานการณ์คงที่ที่มีจำนวนงานรายเดือน สถานะ บทบาทเด็ก
งบประมาณ และผู้เข้าร่วมต่างกัน โดยจำนวนผู้เข้าร่วมแยกอายุ/เพศรวมตรงกับยอดกิจกรรม
ระบบอัปเดตตัวอย่างรุ่นเดิมเฉพาะรายการที่ยังไม่ได้แก้ไข ไม่เพิ่มรายการที่เคยลบกลับมา
ข้อมูลเด็กแต่ละรายมีสถานการณ์ครอบครัวและการศึกษาที่สัมพันธ์กับอายุ
ผู้ดูแลสัมพันธ์กับที่อยู่อาศัย ข้อมูลคำปรึกษาตรงกับข้อมูลเด็ก และสัดส่วน
ผู้เข้าร่วมแตกต่างกันตามกิจกรรม การอัปเดตรองรับข้อมูลตัวอย่างทั้งรุ่นเดิมและรุ่นกราฟ

```sh
npm run build
npm test
```

ข้อมูลเด็กแยกระหว่างคำปรึกษาและงานอัยการ ไม่ตัดซ้ำข้ามงาน คำปรึกษาอ้างอิงในงานอัยการเป็นเพียงการเชื่อมรายการ ไม่คัดลอกหรือรวมข้อมูลเด็ก กิจกรรมนับผู้เข้าร่วมเป็นคน-ครั้ง ข้อมูลเด็กสำหรับการวิเคราะห์เป็นข้อมูลปัจจุบันในรายการ ไม่ใช่ประวัติย้อนหลัง

ช่อง F01–F53 และ P01–P23 มาจาก Excel ในโครงการ โดย src/schema.json เก็บรายการช่องและตัวเลือกจากชีตอ้างอิง ตัวเลือกสำนักงานและพื้นที่เพิ่มเติมเป็นข้อมูลสาธิต ไม่ใช่ทะเบียนหน่วยงานจริง วันที่เก็บเป็น ค.ศ. และแสดงเป็น พ.ศ. ปีงบประมาณคำนวณจากวันที่ของงาน

ปุ่มคืนค่าข้อมูลตัวอย่างลบการเปลี่ยนแปลงในเบราว์เซอร์นั้น CSV ส่งออกทุกรายการที่เข้าเงื่อนไข ส่วนการพิมพ์ใช้หน้ารายงานในเบราว์เซอร์ ไม่มี backend หรือระบบสิทธิผู้ใช้
